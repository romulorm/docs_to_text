# Docs to Text Converter App

Docs to Text Converter is a desktop app build with Python customtkinter and docling to convert many types of documents in JSON, Text, Mardown or HTML.

## Input file types
Documents: PDF, PPTX
Images: JPEG, PNG, TIFF, WEBP, BMP
Audio: MP3, WAV

## Output file types
JSON, Text, Mardown or HTML.

## Requirements:
Python 3.13 with PEP8
Stack: Customtkinter and docling
The app has a file input box, select boxes for Input and Output and a Convert button.
The app has a select box for "dark-blue" color theme (default) or blue.
Should have EN and PT-br (default) languages.

Use Context7 MCP (Code Library) as needed.
